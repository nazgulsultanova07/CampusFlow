# CampusFlow

Веб-приложение для бронирования аудиторий кампуса: поиск свободных пространств по дате, времени, вместимости и оборудованию, оформление бронирований и управление аудиториями.

**Демо:** https://campusflow-peiv.onrender.com/
⚠️ Доступ к демо возможен только через VPN: домен `onrender.com`, можно запустить локально 

## О проекте

CampusFlow помогает студентам, преподавателям и сотрудникам кампуса быстро находить подходящие аудитории и бронировать их без пересечений. Вместо ручного согласования расписания пользователь задаёт параметры — система показывает только те пространства, где есть подходящие свободные интервалы.

Основные возможности:

- 🔍 **Умный поиск аудиторий** — фильтрация по дате, времени, вместимости и оборудованию.
- 🕒 **Свободные интервалы** — отображение доступных слотов для каждой аудитории (например, 09:00–18:00).
- 📋 **Результаты с сортировкой** — «Сначала подходящие» и другие варианты упорядочивания.
- 📅 **Мои бронирования** — личный раздел с текущими и предстоящими бронями.
- 🛠 **Управление кампусом** — администрирование аудиторий и расписания.
- 🏫 **Каталог из 12 аудиторий** с описанием вместимости и оснащения.

## Технологии

- **Frontend:** HTML5, CSS3, JavaScript (интерактивный интерфейс и взаимодействие с API).
- **Backend:** Python + Flask (обработка запросов, авторизация, бронирование аудиторий, поиск свободных слотов и проверка конфликтов).
- **Хранение данных:** JSON-файл (`data.json`) для хранения информации о пользователях, аудиториях и бронированиях.
- **API:** REST API, формат обмена данными — JSON.
- **Деплой:** Render.
- **Система контроля версий:** Git и GitHub.
